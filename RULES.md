# ПРАВИЛА РАБОТЫ ДЛЯ AI-АССИСТЕНТА (Continue, Copilot и др.)

## Приоритетная задача
При **любом** запросе на изменение или создание кода **в первую очередь** изучи дневник разработки:
`https://github.com/ArchakovBullet/finlab-diary`
Особое внимание удели файлам:
- `README.md` — актуальный статус проекта.
- Последним записям в `WORK_LOG_*.md` — последние задачи, решения и планы.
Это поможет избежать предложений, противоречащих уже принятым решениям.

## Стек технологий
- **Python:** 3.12
- **Данные:** `polars` (основная библиотека), `pandas` (допустима для бэктестинга в `backtrader`)
- **API Мосбиржи:** `MOEXPy` (локальная библиотека в проекте)
- **Бэктестинг:** `backtrader`
- **ML:** `xgboost`, `scikit-learn`
- **Дашборд:** `streamlit`, `plotly`
- **Уведомления:** `vk_api`

## Архитектура проекта
- **Сборщики данных:** `FinLabPy/DataCollectors/`. Каждый сборщик — отдельный `.py` файл, который можно запустить независимо.
- **Стратегии:** `FinLabPy/Strategies/`
- **Индикаторы:** `FinLabPy/My_Indicators/`
- **Утилиты:** `FinLabPy/Utils/`
- **Конфигурация:** Настройки в `Config.py` и переменные окружения (например, `MOEX_TOKEN`)
- **Данные:** Хранятся в `/root/finlab/data/` на сервере. Каждый тип данных — в своей подпапке (futoi, hi2, supercandles и т.д.)

## Стиль кода
- **Язык:** Весь код, комментарии, документация и строки для пользователя — строго на РУССКОМ языке.
- **Логирование:** Всегда используй логгер, настраиваемый через `FinLabPy.Utils.setup_logger`. Он пишет и в консоль, и в файл.
- **Сборщики:** Структура каждого сборщика должна быть как в `futoi_collector.py`:
  - Заголовок с описанием
  - Константы (TICKERS, DATA_DIR, LOOKBACK_DAYS)
  - Основная функция `collect_...()`
  - Функция `merge_with_existing()` (если нужно)
  - Функция `main()` с визуальным разделением лога (`=====...====`)
- **Комментарии:** Комментируй только сложную или неочевидную логику.

## Workflow при добавлении новых функций
При добавлении нового сборщика или фичи всегда предлагай:
1. **Код** самого сборщика/индикатора
2. **Регистрацию в cron** (если это периодическая задача)
3. **Добавление в `check_collectors_health.py`** для мониторинга
4. **Регистрацию в `vk_bot.py`**, чтобы бот мог отдавать по нему статистику
5. **Запись в дневник (`WORK_LOG_*.md`)** о проделанной работе
